# ShopyZone - Jersey E-Commerce Website

A dynamic, full-stack e-commerce web application designed for sports enthusiasts to browse and purchase their favorite team jerseys.

## 🚀 Features
* **Product Catalog:** Browse, filter, and view various sports jerseys.
* **Shopping Cart:** Add, update, and remove items dynamically.
* **User Authentication:** Secure signup and login functionality.
* **Database Management:** Structured MySQL database to store user information, products, and order history.
* **Responsive UI:** Clean and interactive user interface built with semantic HTML and custom CSS.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** MySQL
